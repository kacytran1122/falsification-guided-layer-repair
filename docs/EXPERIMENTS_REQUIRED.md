# Fixes That Require New Experiments or New Run-Time Evidence

1. **Reproduce the shallow baseline first.** Match a trusted PyG/DGL implementation and a published-range depth-2 GCN result on the identical split before running deep variants.
2. **Run the confirmatory dataset/backbone grid.** Use GCN, GraphSAGE, GATv2, and GCNII on homophilous, modern heterophilous, and long-range tasks. Determine the paired-seed count with a power or simulation analysis; ten seeds is a minimum design target, not proof of adequate power.
3. **Strengthen the location control.** Constrain the diagnosed target to at most `L/2` layers (or a fixed prespecified window). For every seed, sample at least four same-cardinality masks using the same repair and require Jaccard overlap at most 0.5 with the target. If this cannot be achieved, do not make a localization claim.
4. **Give methods equal tuning budgets.** Publish identical trial counts, validation rules, schedulers, and search spaces for plain, PairNorm, residual, uniform, targeted, and mismatched conditions.
5. **Run selector sensitivity and ablations.** Sweep `epsilon` in `{0.3,0.4,0.5,0.6,0.7}`, test threshold-free change points, remove each diagnostic channel, alter the tie rule, and report onset stability.
6. **Log one row per epoch.** Required fields: `run_id, dataset, backbone, seed, condition, depth, epoch, train_loss, val_loss, train_accuracy, val_accuracy, learning_rate, allocated_bytes, reserved_bytes, epoch_seconds, cumulative_seconds, stopping_reason`. At run completion, also store the selected epoch, the one-time test result, parameter count, FLOPs/MACs, and throughput.
7. **Use a valid timing protocol.** Warm up the GPU, call `torch.cuda.synchronize()` around measured regions, separate training/evaluation/diagnostic time, repeat timing trials, and log epochs executed.
8. **Profile efficiency.** Record trainable parameters, validated sparse FLOPs/MACs, peak allocated/reserved/NVML process memory, throughput, and optionally integrated NVML energy.
9. **Save predictions and logits.** Compute macro-F1, balanced accuracy, per-class recall, confusion matrices, NLL, Brier score, and calibration without estimating values.
10. **Execute the frozen hierarchical statistical plan.** Test repair viability (targeted versus plain) before location (targeted versus low-overlap controls), and location before prescription (selected repair versus mismatched repairs). Report paired mean differences, 95% CIs, paired permutation tests, paired effect sizes, and Holm correction over the declared family.
11. **Archive provenance.** Store checkpoints, raw JSONL, full manifest, stdout/stderr, exact command, `pip freeze`/environment lock, CUDA/cuDNN versions, determinism flags, dataset files or immutable revision, and hashes in a timestamped immutable archive.
12. **Validate metric implementation.** Add toy-graph unit tests for energy, rank, gradient-ratio indexing, masks, and a reference comparison for preprocessing/message passing.
13. **Protect the test set.** Freeze data splits, selector thresholds, masks, tuning spaces, primary outcomes, exclusions, and analysis code before confirmatory training; use validation data for all choices and evaluate the held-out test set once.
